# OneOverX

在反比例函数 y = 1/x 中，当 x（社会、技术与信息）趋向无穷大时，y（个人的专注、内核与本质）趋向 0——却永远不等于 0。

OneOverX 是一段探索之旅：在无限扩张的世界（x）里，寻找那个独特、纯粹、独立的自我（1）。

在金融领域，Beta 代表系统性趋势；在技术领域，Beta 是永不停歇、持续迭代的原型状态。这是一个拒绝"假完美"、拥抱"终身开放测试"的频道。

---

OneOverX 由 Joey 制作。

我学的是金融，是一个纯粹的文科生。在书籍和电影里，我找到志趣相同的人和世界；在技术的世界里，我喜欢理科——编程可以从零搭建出一个东西，这种感觉很好。我有很多兴趣，很多想深入了解的东西，正在慢慢培养自己的 taste 和专业性。

这个杂志有两个栏目，分别展现我的两个侧面：

**Beta Project** — 自我探索、心理研究与生活方式实验。向内看，关于成为自己。

**X Factor** — 经济社会、历史、人物、AI 科技等来自外部的 X 变量观察。向外看，关于理解世界。

---

终此一生，我们都在学着更好地消解无聊与认识自我。

这是我选择的方式。
